# ClassVoice — ضبط هوشمند صدا، تبدیل به متن کلاس و خروجی PDF

یک اپلیکیشن اندروید سریع و مینیمال برای ضبط صدای کلاس‌های درس، نام‌گذاری هوشمند فایل‌ها بر اساس برنامه کلاسی هفتگی (روز هفته - نام درس - شماره جلسه - شماره پارت)، تبدیل صوت به متن از طریق رله ورکر کلودفلر (Cloudflare Worker Relay) و هوش مصنوعی، و تولید خروجی PDF تمیز و متن قابل کپی.

### User Review & Critical Decisions

> [!IMPORTANT]
> تصمیمات کلیدی بر اساس پاسخ‌های شما تأیید شدند:
> - **رله کلودفلر (Cloudflare Worker Relay)**: آدرس پیش‌فرض در اپ قرار داده می‌شود و از بخش تنظیمات قابل تغییر و سفارشی‌سازی است. در صورت نیاز امکان فراخوانی مستقیم Gemini API نیز وجود دارد.
> - **نحوه تبدیل صدا به متن**: پس از اتمام ضبط صدا، فایل ضبط‌شده با انکودینگ صوتی استاندارد جهت رونویسی دقیق به مدل Gemini (`gemini-3.5-transcribe` / `gemini-3.8-flash`) از طریق رله کلودفلر ارسال می‌گردد. همچنین برای تجربه همزمان کاربری، زمان‌سنج و شکل‌موج زنده (Audio Waveform) در هنگام ضبط نمایش داده می‌شود.
> - **خروجی PDF و متن**: فایل PDF حاوی عنوان منظم کلاس، تاریخ، زمان و متن کامل پیاده‌سازی شده تولید می‌شود و کل متن در صفحه نمایش نیز با یک کلیک قابل کپی کردن به حافظه (Clipboard) یا اشتراک‌گذاری در پیام‌رسان‌ها خواهد بود.

### ۱. نمای کلی و اهداف اصلی (Overview & Core Concept)

- **هدف کاربری**: دانشجویان و دانش‌آموزانی که می‌خواهند سر کلاس به سادگی دکمه ضبط را بزنند و بدون درگیری با نام‌گذاری‌های دستی، فایل به صورت خودکار به شکل «شنبه - تاریخ - جلسه ۱» نام‌گذاری شود و در انتها متن پیاده‌شده و تمیز با امکان دریافت فایل PDF تحویل داده شود.
- **ارزش محوری**:
  - مدیریت آسان برنامه هفتگی کلاس‌ها (روزهای هفته، نام درس، ساعت شروع و پایان، شماره جلسه جاری).
  - تشخیص هوشمند کلاس جاری بر اساس روز هفته و ساعت فعلی برای پیشنهاد خودکار عنوان ضبط.
  - شمارش خودکار جلسات و پارت‌ها (جلسه ۱، پارت ۱، پارت ۲ و ...).
  - رابط کاربری خلوت، روان و سریع با تم Material 3 مناسب محیط دانشگاه و مطالعه.
  - پشتیبانی کامل از متن فارسی، چیدمان راست‌به‌چپ (RTL) و فونت خوانا در اپ و فایل PDF.

### ۲. تجربه کاربری و طراحی بصری (User Experience & Visual Design)

- **جریان‌های کاربری کلیدی**:
  1. **صفحه اصلی ضبط (Record Screen)**: کارت نمایش کلاس جاری (یا انتخاب سریع درس با چیپ‌های سریع)، نمایش نام پیشنهادی («شنبه - ریاضی مهندسی - جلسه ۳»)، دکمه بزرگ ضبط با انیمیشن پالس و نوار موج صدا، دکمه توقف و تبدیل خودکار به متن.
  2. **صفحه نمایش و ویرایش رونویسی (Transcript & Export)**: نمایش متن تبدیل‌شده با قابلیت کپی فوری، دکمه خروجی PDF، پخش صدای ضبط‌شده با نوار پیشرفت، و دکمه اشتراک‌گذاری.
  3. **صفحه برنامه کلاسی (Schedule Screen)**: تعریف روزها، درس‌ها، شماره جلسه و تنظیم زمان کلاس‌ها با قابلیت ویرایش و افزودن سریع.
  4. **صفحه آرشیو ضبط‌ها (Recordings Archive)**: فهرست تمام جلسات ضبط‌شده همراه با برچسب درس، روز، متن خلاصه، وضعیت رونویسی، دانلود مجدد PDF و پخش صدا.
  5. **صفحه تنظیمات رله (Settings Screen)**: آدرس ورکر کلودفلر، کلید API پشتیبان، و وضعیت اتصال به سرور.

- **جهت‌گیری زیبایی‌شناختی و تم (Visual Theme)**:
  - **پالت رنگی**: تم مدرن سرمه‌ای و کهربایی تیره (Deep Indigo `#1E1B4B`, Slate `#0F172A`, Accent Amber `#F59E0B`, Soft Card `#F8FAFC` / `#1E293B`).
  - **طراحی کنترل‌ها**: دکمه‌های بزرگ با بازخورد لمسی (Haptic Ripple)، تایمر برجسته، نشانگر ضبط در حال اجرا.
  - **سازگاری با اینست‌ها**: رعایت کامل `WindowInsets` و لبه‌به‌لبه (Edge-to-Edge) بدون تداخل با ناوبری و دوربین.

### ۳. تصمیمات فنی و معماری محصول (Key Product Decisions)

- **رله ورکر کلودفلر (Cloudflare Worker Relay)**:
  - اپلیکیشن درخواست تبدیل صدا به متن را در قالب درخواست استاندارد به رله کلودفلر ارسال می‌کند که بار پردازشی را به مدل Gemini منتقل می‌کند.
  - در صورت عدم دسترسی به ورکر، امکان سوئیچ خودکار به REST API مستقیم با کلید محیطی فراهم است.
- **تولید خروجی PDF محلی (Zero-dependency Local PDF Engine)**:
  - استفاده از کتابخانه بومی اندروید `android.graphics.pdf.PdfDocument` برای تولید PDF برداری سریع با پشتیبانی کامل از متن فارسی RTL، تیتربندی و پاورقی استاندارد، بدون نیاز به کتابخانه‌های سنگین خارجی.
- **ذخیره‌سازی آفلاین با Room**:
  - ذخیره کامل سوابق کلاس‌ها، برنامه زمانی و متون پیاده‌شده در دیتابیس لوکال SQLite/Room تا بدون اینترنت نیز تمام یادداشت‌ها در دسترس باشند.

### ۴. معماری فنی و جریان داده‌ها (Technical Architecture & Data Strategy)

```
┌──────────────────────────────────────────────────────────────┐
│                     Jetpack Compose UI                       │
│  [RecordScreen]   [TranscriptDetail]   [ScheduleScreen]      │
│         │                  │                   │             │
└─────────┼──────────────────┼───────────────────┼─────────────┘
          ▼                  ▼                   ▼
┌──────────────────────────────────────────────────────────────┐
│                    MainViewModel & State                     │
│  - Current Recording State & Waveform                        │
│  - Active Schedule Matcher (Day/Time Auto-Naming)            │
│  - Room Database Reactive StateFlows                         │
└──────────────┬───────────────────────────────┬───────────────┘
               │                               │
       Audio & Storage                  Network & Export
               │                               │
               ▼                               ▼
┌──────────────────────────────┐ ┌─────────────────────────────┐
│ Android Audio Engine & Room  │ │ Cloudflare Worker Relay API │
│  - MediaRecorder / AAC Audio │ │  - Worker Endpoint / Gemini │
│  - AppDatabase (ClassDAO)    │ │  - Native PdfDocument Engine│
│  - File Storage (Audios/PDF) │ │  - Share Sheet Integration  │
└──────────────────────────────┘ └─────────────────────────────┘
```

- **نهادهای پایگاه داده (Data Entities)**:
  - `CourseSchedule`: روز هفته (`dayOfWeek`)، نام درس (`courseName`)، زمان شروع و پایان، جلسه فعلی (`sessionNumber`).
  - `RecordingItem`: شناسه، عنوان تولیدشده («شنبه - تاریخ - جلسه ۱ - پارت ۱»)، مسیر فایل صوتی، متن پیاده‌شده، تاریخ و ساعت ثبت، مدت زمان صوت.
- **مدیریت انکودینگ صدا**:
  - ضبط با فرمت سبک و سازگار AAC (MP4 container) با نرخ نمونه‌برداری بهینه برای گفتار که به صورت Base64 به رله ورکر کلودفلر ارسال می‌شود.
- **جریان خروجی PDF**:
  - تولید مستقیم برگه A4 با حاشیه‌های استاندارد و متن راست‌به‌چپ، ذخیره در حافظه محلی و باز شدن پنجره اشتراک‌گذاری اندروید (`Intent.ACTION_SEND` / `ACTION_VIEW`).

### مراحل پیاده‌سازی گام‌به‌گام

1. **پیکربندی وابستگی‌ها و مانیفست**: دسترسی‌های ضبط صدا (`RECORD_AUDIO`)، اینترنت، و رجیستر کردن `FileProvider` برای اشتراک PDF.
2. **لایه داده و Room Database**: ایجاد جداول برنامه کلاسی و یادداشت‌های صوتی همراه با مخزن (Repository).
3. **موتور ضبط صدا و منطق نام‌گذاری هوشمند**: سرویس ضبط صدا و ماژول تولید خودکار عنوان بر اساس روز و ساعت جاری.
4. **سرویس رله کلودفلر و تبدیل صوت به متن**: ماژول رله ورکر و مدیریت درخواست‌های صوتی با مدل Gemini.
5. **موتور تولید PDF و به اشتراک‌گذاری**: طراحی ساختار برگه PDF و کپی سریع متن در حافظه.
6. **رابط کاربری Compose**: طراحی صفحات ضبط ساده، برنامه کلاسی، جزئیات متن و آرشیو یادداشت‌ها.
7. **آیکون برنامه و بیلد نهایی**: تنظیم متاداده و ساخت نسخه پایدار.
